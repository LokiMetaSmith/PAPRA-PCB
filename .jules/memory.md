## Archived: 2026-11-02

* Firmware programming requires a UPDI programmer and uses the Arduino IDE with the megaTinyCore library.
* The PCBA requires 12V nominal DC power (center pin positive) or a Milwaukee M12 battery for bring-up, and provides a 5V regulator output for UPDI programming.
* The repository is for the PAPRA Printed Circuit Board Assembly (PCBA) project, containing hardware designs (e.g., PaprControlPCB) and supporting various ATtiny microcontrollers (e.g., ATtiny1614, ATtiny1624).
